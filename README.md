# Reservoir & CO2 Storage Lab — Website (v3)

전북대학교 석유공학연구실 공식 웹사이트입니다.

- **배포·관리자 설정 방법**: `SETUP-GUIDE.md`를 여세요. (GitHub Pages 배포 → /admin 편집 페이지 연결)
- **콘텐츠 수정**: 논문·소식·과제·구성원은 `/admin` 또는 `data/*.json`에서, 페이지 문구는 각 `.html`에서 수정합니다.
- 한국어(`.ko`)와 영어(`.en`) 텍스트가 나란히 있으니 **둘 다 수정**하세요.
- 디자인·구조 변경용 빌드 도구는 배포 패키지의 `_build` 폴더에 있습니다.
